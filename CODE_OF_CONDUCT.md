# Code of conduct

Be respectful, constructive and considerate in issues, pull requests and project discussions. Welcome different experience levels and backgrounds. Critique the work, give actionable feedback and respect privacy.

Harassment, discrimination, threats, sexualized conduct, doxxing and persistent personal attacks are unacceptable. Do not publish private correspondence or sensitive user data.

Maintainers may edit or remove harmful content, close discussions, restrict participation or ban repeated or severe violations. Decisions should consider context and impact. Maintainers are held to the same standard.

Report conduct concerns privately through a maintainer contact already published on their GitHub profile. A dedicated confidential contact is pending; do not post identifying details publicly. If no private channel is available, request a private reporting channel without exposing the incident or affected people.
