# Support

Use GitHub issues for reproducible bugs and scoped feature requests. Search existing issues first and include component, revision, runtime versions, sanitized steps and observed errors. Do not share secrets, payment details, personal images or tenant records.

For local setup start with README.md and backend/README.md. Additional organization-service code and credentials are not bundled. Custom UI presets may be unsupported by the current backend.

Security reports follow SECURITY.md. Conduct concerns follow CODE_OF_CONDUCT.md. Community support is best effort; there is no support SLA or guaranteed hosted demo availability.
