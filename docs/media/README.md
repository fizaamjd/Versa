# Versa demo media

The standalone HTML is the editable presentation source. Its matching export is a 64-second, 1200 × 1200, 24 fps H.264 video.

The presentation uses actual captures of the revised Next.js frontend: landing, Transformation Engine, Creation Engine, compliance reports, archive and dashboard. Titles follow the smaller Archivo scale. Phone layouts use focused crops and larger captions; empty report/archive screens remain empty and have shorter holds. The five-format illustration uses the same preset names and pixel sizes as the frontend.

Captures use a local synthetic account and original sample artwork in sample-creative.svg. No customer data, paid generation, model output, measured processing speed or quality score is claimed. The source preview is labelled as an original image; it is not presented as a generated result.

Checksums record the exact HTML and video. The capture provenance also records source file hashes so the UI and presentation can be compared.
